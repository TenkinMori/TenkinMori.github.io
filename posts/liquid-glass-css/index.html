液态玻璃：用 CSS 还原 iOS 的玻璃质感

2026年11月11日3 分钟阅读设计CSS

第一次看到 iOS 的新界面时，印象最深的不是图标，而是那种像一层薄玻璃浮在内容上面的感觉：背景的颜色会透上来，边缘有一道亮边，移动的时候高光跟着走。

把这套感觉搬到网页上，其实不需要什么黑科技，主要是四件事叠在一起。

一、模糊，而且要饱和

玻璃的第一要素是背景虚化。CSS 里就是 backdrop-filter：

.glass {
  background: linear-gradient(
    135deg,
    rgba(255, 255, 255, 0.7),
    rgba(255, 255, 255, 0.4) 50%,
    rgba(255, 255, 255, 0.56)
  );
  backdrop-filter: blur(26px) saturate(185%);
  -webkit-backdrop-filter: blur(26px) saturate(185%);
}

blur 负责虚化，saturate 负责让透上来的颜色更「鲜」。只加模糊不加饱和，看起来会发灰，像蒙了一层雾。

另外背景本身不能是纯色。这个站的背景是几团大范围的高斯模糊色块，慢慢漂移；玻璃只有盖在有颜色的东西上，才有东西可透。

二、边缘是玻璃的灵魂

真实的玻璃边缘会亮，因为光在厚度里折射了一次。网页上可以拆成两条：

.glass {
  border: 1px solid rgba(255, 255, 255, 0.7);
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.9), /* 顶部亮边 */
    0 28px 70px -28px rgba(23, 26, 56, 0.38); /* 柔和投影 */
}

inset 的高光是关键。没有它，半透明面板会像一块塑料片；有了它，边缘才「立」得起来。

三、让高光跟着鼠标走

静态高光已经不错，动态的更接近真实。做法很简单：监听指针位置，写进两个 CSS 变量，再用径向渐变画出来。

.glass::before {
  content: '';
  position: absolute;
  inset: 0;
  z-index: -1;
  background: radial-gradient(
    460px circle at var(--mx, 50%) var(--my, 0%),
    rgba(255, 255, 255, 0.6),
    transparent 55%
  );
  opacity: 0;
  transition: opacity 0.45s ease;
}

.glass:hover::before {
  opacity: 1;
}
el.addEventListener('pointermove', (e) => {
  const rect = el.getBoundingClientRect();
  el.style.setProperty('--mx', `${e.clientX - rect.left}px`);
  el.style.setProperty('--my', `${e.clientY - rect.top}px`);
});

注意 z-index: -1 要配合父元素的 isolation: isolate，否则高光会跑到卡片后面去。

四、别让它太干净

真实的玻璃不完美：有灰尘、有细微的划痕。网页上是加一层很淡的噪点：

.grain {
  position: fixed;
  inset: 0;
  opacity: 0.04;
  pointer-events: none;
  mix-blend-mode: overlay;
  background-image: url("data:image/svg+xml,...feTurbulence...");
}

噪点很淡，淡到单独看几乎看不见，但它能消掉大面积渐变里那种「数字感」的平滑，让画面更接近照片。

性能与降级

backdrop-filter 是吃 GPU 的，大面积使用要克制：

  • 别给整页加，只给需要浮起来的元素加
  • 动画尽量用 transform 和 opacity，别动 filter
  • 提供降级：@supports not (backdrop-filter: blur(1px)) 时换成更实一点的颜色
  • 尊重 prefers-reduced-motion 和 prefers-reduced-transparency

这个站里，导航、卡片、文章容器都用了同一套配方，只是圆角和模糊半径不同。统一的材质，比每种卡片各做一套更容易显得干净。

玻璃只是材质，真正决定好不好看的，还是排版、留白和节奏。材质用对了是加分项，用过头就是灾难。
